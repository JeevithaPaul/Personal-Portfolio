# Jeevitha Paul - Personal Portfolio

A responsive personal portfolio and blog application built using React, Node.js, Express, MongoDB, and Firebase Authentication.

## Features

- Responsive personal portfolio website
- Professional developer profile
- About Me section
- Technical Skills section
- Projects showcase
- Personal blog section
- Blog likes
- Firebase Login and Signup authentication
- Contact section
- GitHub and LinkedIn links
- CV download
- Responsive mobile navigation
- Modern dark purple and pink UI

## Projects

### TinyTulip - Baby Clothing & Essentials
E-commerce website for baby clothing and essentials.

### Weather App
Weather application that displays weather information using a weather API.

### BulkMail
Full-stack bulk email application using React, Node.js, Express, Nodemailer, and MongoDB.
